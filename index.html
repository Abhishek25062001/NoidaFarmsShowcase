At a glance

Three surfaces, one backend

Noida Farms is a customer app, an admin panel and a vendor dashboard, all sharing a single Node.js and MongoDB backend.

What it does

Find a farmhouse, hold the dates, pay

Guests search farmhouses, check which dates are open and book. Vendors keep their own listing, photos and availability current. Staff handle bookings and sign-in settings from an admin panel.

Farmhouse discovery

Browse farmhouses with search and filters, then open a detail view with photos, amenities and pricing.

What I built

Engineering highlights

The parts of Noida Farms that took the most careful work.

  1. 01Three surfaces on one backend

    A React Native customer app, a React Native admin panel and a vendor dashboard, all served by a single Node.js API over MongoDB with Mongoose models.

  2. 02Farmhouse listings, search and filters

    Listing, search, filtering and detail views, covering photos, amenities and pricing for every farmhouse on the platform.

  3. 03Availability and booking

    Vendors keep their own calendar, guests book against it, and staff can place a booking manually from the admin side when it comes in another way.

  4. 04Payments and vendor payouts

    Guest payments on one side of the ledger and vendor payouts on the other, settled against the bank details held on each vendor profile.

  5. 05Server-generated PDF invoices

    Every booking produces a PDF invoice, generated on the server with PDFKit rather than assembled on the device.

  6. 06Sign-in that admins control

    Email, WhatsApp and Google sign-in, with admin toggles that decide which methods are offered — so a method can be turned off without shipping a release.

How it fits together

Three front ends, one API, one database — so guests, vendors and staff all read and write the same records.
